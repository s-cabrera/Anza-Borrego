# Anza Borrego Stargazing Trip: install on a Pixel

This folder is an installable web app (PWA). It works offline once opened one time.

## Host it (free, about 5 minutes)
1. Make a free GitHub account and create a new public repository, for example `anza-trip`.
2. Click "Add file" > "Upload files", drag in everything in this folder (keep the `icons` folder), and commit.
3. Open Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/anza-trip/`.

(Netlify Drop at app.netlify.com/drop also works: drag the folder in and it gives you a link.)

## Install on the Pixel
1. Open the link in Chrome on the Pixel.
2. Tap the three-dot menu > "Install app" (or "Add to Home screen").
3. Open it from the home screen like any app. Load it once with signal, and after that it works offline in Anza-Borrego.

Checks are saved on the phone. Each phone keeps its own checks, so Matt and Steph each check off their own copy.
